| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | answer.json / supporting_document.json writers | medium | mitigate | Serialize only via Pydantic `model_dump_json` / `model_dump(mode="json")` from typed ClaimBundle fields — never string-interpolate raw file bytes into JSON |
| T-03-02 | Information Disclosure | logging in workflows/pipeline.py | medium | mitigate | Log claim folder names and artifact paths only — never log full description letter text or DocumentData.raw_text (CLAUDE.md: no PII in logs) |
| T-03-03 | Path Traversal / write escape | output_root / claim_dir.name | high | mitigate | Resolve claim output as `output_root / claim_dir.name` where `claim_dir` comes from `_discover_claim_folders` / known claim dirs; refuse to write if `claim_dir.name` contains path separators or `..` (validate at boundary before mkdir) |
| T-03-04 | Denial of Service | Docling/LLM via composed readers | low | accept | Unit path uses injectable readers; live stack optional (Phase 1 stance). Soft-fail batch is 03-02 |
| T-03-SC | Tampering | pip/uv package installs | high | mitigate | No new packages this plan — compose existing preprocessing stack already in lockfile |

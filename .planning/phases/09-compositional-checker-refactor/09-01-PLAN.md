# Plan 09-01: Compositional checks, gates, and suite

**Goal:** Decompose `Checker` into composable checks sharing one `LlmCheckClient`, add a `Gate` protocol for date gates, and build both once in `ClaimPipeline`. Behavior-preserving (CONTEXT D-06..D-08).

## Task 1 — `compliance.llm.checks` package
- `base.py`: `CheckerMode`, `CheckOutcome`, `CheckContext(description, document, booking)`, `Check` protocol, `normalized_text`.
- `client.py`: `LlmCheckClient(model, chat, retry)` with `boolean_result(...) -> bool | None` and `extracted_name(...) -> NameExtraction`; owns `BooleanCheckResult` / `ExtractedNameResult`. Retry/parse context labels and warning messages unchanged.
- `boolean.py`: `Polarity`, `BooleanLlmCheck(name, client, prompt, polarity, message)`; message builders `claim_and_document_message` / `document_only_message`.
- `containment.py`: `ContainmentCheck(fallback: BooleanLlmCheck)` — deterministic hit → PASS, else fallback.
- `identity.py`: `IdentityCheck(client, prompt, max_edit_distance)`; booking-name parsing, role-note skip, containment, extraction, Levenshtein as module helpers.
- `suite.py`: `CheckSuite(checks)` ordered; `from_config(CheckingConfig, chat)`; `run(modes, context)`.
- Delete `llm/checker.py`; update `llm/__init__.py`.

**Verify:** module imports; per-check tests pass.

## Task 2 — `compliance.policy.gates`
- `Gate` protocol (`name`, `fires(context, *, today) -> bool`), `DepartureGate`, `SuspiciousDatingGate`, `gates_from_config(CheckingConfig)` (departure only when `departure_uncertain_enabled`).

## Task 3 — Runner + pipeline wiring
- `run_checks(context, rule_set, gates, suite)`; `CheckerRunResult` unchanged; LLM checks skipped when any applicable gate fires.
- `ClaimPipeline.__init__` builds suite + gates once; `_run_checker_node` passes them.
- Update `CheckOutcome` / `CheckerMode` imports in `policy/decision.py`, `policy/state.py`, tests.

## Task 4 — Tests
- Replace `tests/test_llm/test_checker.py` with `tests/test_llm/test_checks/` (containment, boolean, identity, client transport, suite order). Drop the unsupported-mode test (string dispatch no longer exists).
- `make test` green; pipeline tests unchanged in behavior; `mypy` + `ruff` clean on touched files.

## Success criteria
- No class takes more than its own prompt/threshold plus the shared client.
- `CheckingConfig` is read once per pipeline, not per claim.
- Full fast lane green with identical pipeline-test expectations.

# S03: Docling DocumentReader + InformationExtractor + pipeline

**Milestone:** M001
**Slice:** S03

**Goal:** Implement DocumentReader (FormatConverter → PNG, then Docling), InformationExtractor + DescriptionReader, and orchestrate the full pipeline to write processed.json per claim
**Demo:** Run pipeline on all 25 claims; show processed.json for claim 16 (approval, medical image + train md) and claim 1 (sparse md + png booking confirmation)

## Must-Haves

- DocumentReader applies FormatConverter.to_png **before** Docling; formats list from config; maps extracted text → extensible **DocumentData** (person, date, + arbitrary `fields`; confidence / human_in_the_loop). InformationExtractor takes a Pydantic model + config LLM model + config prompt. DescriptionReader uses InformationExtractor targeting BookingData. Pipeline writes processed.json for all 25 claims.

## Proof Level

- This slice proves: Unit tests for DocumentReader order (FormatConverter then Docling, mocked), InformationExtractor (mocked LLM), DescriptionReader, pipeline discovery. Integration: full pipeline on real data/ for all 25 claims.

## Integration Closure

Final slice — consumes S01 models/config and S02 Reader ABCs + FormatConverter. Output is processed.json consumed by future milestones.

## Verification

- Pipeline logs per-claim status, format conversions, Docling confidence warnings, and extraction failures without aborting the run.

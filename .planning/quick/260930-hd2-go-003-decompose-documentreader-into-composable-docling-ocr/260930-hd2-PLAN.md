# Plan: GO-003 Decompose DocumentReader (R16 god object)

**Goal:** Split `DocumentReader`'s wide same-kind constructor and mixed layers into composable collaborators (Phase 9 `CheckSuite` shape). Behavior-preserving for OCR text, HITL, Benford early DENY, vision retry, and signature verify.

## Task 1 — Extract collaborators
- Introduce small pieces (names flexible) e.g.:
  - Docling primary OCR path (formats, confidence, converter, preprocessor)
  - Vision OCR retry (`Llm`/chat seam + `OcrRetryConfig`)
  - Signature verify (detector + OCR-retry signature settings — reuse GO-001 API if already landed)
  - Optional Benford gate
- Shared transport stays out of domain rules (same principle as `LlmCheckClient`).
- Prefer `DocumentReader.from_config(prep, ocr_retry, extraction_failure, benford, deps)` or compose at the reader construction site without field fan-out of 5+ same-kind knobs.

## Task 2 — Preserve public read contract
- Keep `DocumentReader.read(path)` outcomes identical: DENY/fraud on Benford fail, HITL flags, `SignatureDetectionError` raise-through, vision retry triggers.
- Update construction in `claim_batch._process_single_claim` only as needed for the new API; full once-per-pipeline lifetime is **GO-004**.
- Update preprocessing tests; check off GO-003 in `.gsd/refactor.md`; note LOGIC.md if it names the old constructor shape.

## Verify
- `make test` green (or preprocessing + extraction_failure suites at minimum).

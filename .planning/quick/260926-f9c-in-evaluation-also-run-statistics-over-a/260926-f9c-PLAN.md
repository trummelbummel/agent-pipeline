## Discretion (no CONTEXT.md D-XX)

- New focused module `src/evaluation/analysis_stats.py` (do not bloat `Evaluator`, which scores predicted vs GT only).
- Default artifact names: `analysis_stats.json`, `analysis_stats_visualization.png` under `results_dir`.
- One multi-panel PNG (not separate files per series).
- Soft-skip missing/invalid `analysis_result.json` with WARNING branch log; always write stats JSON + PNG even when `n_claims=0`.
- Boolean checkers: count only keys present on each payload among a fixed allowlist matching analysis output (`checker_containment`, `checker_contradicts`, `identity_check`, `identity_unclear`, `signature_check`, `healthy_check`, `checker_missing_documentation`, `human_in_the_loop`, `document_has_signature`); rate = true_count / present_count.
- Label series: flatten `coverage_labels`, `reason_labels`, `document_labels` (display-name lists) into separate frequency maps.
- Reuse `_validate_claim_dir_name` + results_dir claim-folder discovery pattern from `Evaluator._discover_claim_ids` (sort via `_claim_sort_key`); read filename from `config.preprocessing.artifacts.analysis_result`.
- PIL only (reuse `_load_font` / ImageDraw patterns in `visualization.py`); no new deps.
</context>

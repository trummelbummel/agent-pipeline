## Publication contract (as implemented)

1. Stage at `results_dir/.staging/{run_id}/{claim_id}/` after claim-id validation.
2. Write bodies, flush + `os.fsync` each file, fsync staging.
3. `os.replace` each artifact into `results_dir/{claim_id}/`.
4. Write + fsync manifest in staging, `os.replace` into claim dir **last** (commit point).
5. Fsync claim dir; remove empty staging claim/run/`.staging` dirs.

**Validity:** generation is current iff `run_manifest.json` exists and every named artifact's `run_id` equals the manifest `run_id`. Missing manifest = legacy (P-04).

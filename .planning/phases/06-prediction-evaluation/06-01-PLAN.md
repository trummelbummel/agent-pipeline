Lock these for executors (do not revisit without developer override):

- **A1 (package):** Public package lives at `src/evaluation/` per ROADMAP (not under `compliance/`). Hatch wheel `packages` must include `src/evaluation` alongside existing entries (`src/compliance`, and `src/api` if already present from Phase 05).
- **A2 (artifacts compared):** Score `predicted_answer.json` under `preprocessing.results_dir` vs `answer.json` under `preprocessing.data_dir`. Both are GroundTruth-shaped (`decision`, optional `explanation`, optional `acceptable_decision`). Do not score `analysis_result.json` (coverage/reason/document labels — different schema).
- **A3 (config):** Add required `evaluation:` section with `labels: [APPROVE, DENY, UNCERTAIN]` and `metrics_artifact: evaluation_metrics.json`. Typed as `EvaluationConfig` on `AppConfig`.
- **A4 (match rule):** A pair matches when `pred.decision == gt.decision`, OR when `gt.acceptable_decision` is a non-nan string and `pred.decision == gt.acceptable_decision` (see claim 13/20/23 UNCERTAIN+DENY patterns).
- **A5 (metrics):** Hand-roll confusion matrix / accuracy / macro F1 with plain Python (no new sklearn dependency — avoids package-legitimacy gate). Confusion matrix: rows = true labels, cols = predicted labels, axis order = `config.evaluation.labels`. Accuracy = mean(matches). For F1, use effective predicted label = `gt.decision` when the pair matches, else `pred.decision`; macro-average F1 over all config labels (zero-support class contributes 0.0).
- **A6 (path safety):** Call `_validate_claim_dir_name` before joining claim_id under roots; build paths with `Path(config_value) / claim_id / artifact_name` only — never hardcode `data/raw` or `data/results`.
- **A7 (parse):** Reuse `AnswerReader` (or `GroundTruth.model_validate` after `json.loads`) for both files — JSON only; no pickle/marshal.
- **A8 (logging):** Log claim_id and metric scalars only — never explanation text.
- **A9 (specless):** Phase requirement IDs are null/TBD — no REQ probe predicates; coverage is ROADMAP goal only.
- **A10 (Nyquist):** Research skipped → no VALIDATION.md; still ship solid automated verifies here.

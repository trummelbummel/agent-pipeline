# S02: Reader/Preprocessor ABCs + FormatConverter + Answer + Markdown

**Milestone:** M001
**Slice:** S02

**Goal:** Establish extensible Reader and Preprocessor ABCs, FormatConverter (→ PNG), and implement AnswerReader + MarkdownReader with key normalization/translation
**Demo:** Convert a webp sample to PNG via FormatConverter; read `data/claim 10/answer.json` and `data/claim 22/supporting1.md` (Spanish keys) into GroundTruth / BookingData

## Must-Haves

- Reader ABC (`reader.py`) and Preprocessor ABC (`preprocessing.py`). FormatConverter in `preprocessing.py` converts configured formats to PNG (Pillow). AnswerReader → GroundTruth. MarkdownReader → BookingData via key normalize/translate. Missing fields = np.nan.

## Proof Level

- This slice proves: Unit tests for FormatConverter (webp/jpg → PNG, png passthrough), answer variants, markdown EN/ES/sparse. mypy clean.

## Integration Closure

ABCs, FormatConverter, and concrete readers used by S03 DocumentReader (PNG-first then Docling) and pipeline.

## Verification

- Log unknown markdown keys as warnings. FormatConverter logs source format → PNG conversions.
